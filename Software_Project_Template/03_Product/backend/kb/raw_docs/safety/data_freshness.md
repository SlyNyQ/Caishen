# Data Freshness

Market data can be delayed, incomplete, adjusted, revised, or unavailable. Every time-sensitive value should include a source timestamp when available.

Caishen returns an unavailable or stale status when it cannot verify a market value. Missing values must not be replaced with guesses.

Public web sources are fetched at a specific time and may change later. Source summaries are context aids, not substitutes for reading the original material.

Before making a consequential decision, verify current prices, corporate actions, filings, and other relevant facts using primary or regulated data sources.
