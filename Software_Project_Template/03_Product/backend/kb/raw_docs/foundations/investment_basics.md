# Investment Basics

An investment thesis is a testable explanation of why an asset may create value, what evidence supports that view, and what evidence would invalidate it. A useful thesis separates observed facts from assumptions and identifies the time horizon over which the idea can be evaluated.

Return is the gain or loss on an investment over a period. Total return can include price changes and distributions such as dividends. Historical return is descriptive, not a promise of future performance.

Diversification spreads exposure across securities, sectors, geographies, or asset classes. It can reduce company-specific risk, but it cannot eliminate broad market risk or guarantee against loss.

Before comparing securities, use consistent periods, currencies, and data definitions. A higher return is not automatically better when it required materially higher risk.
