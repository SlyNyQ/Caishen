# Analysis Methods

Fundamental analysis studies a company's business model, financial statements, competitive position, management decisions, and valuation. Useful questions include whether revenue quality is durable, cash generation supports the business, and valuation assumptions are explicit.

Market-based analysis studies price, return, volatility, volume, and relative performance. These measures describe market behavior but do not establish a company's intrinsic value.

A security comparison should use the same period and metric definitions for each ticker. It should state unavailable values rather than infer or invent them.

Public-source analysis should distinguish primary disclosures from commentary. Company filings and official releases can still contain forward-looking statements and should be read alongside risks and independent evidence.
